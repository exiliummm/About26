# About26 🌊

An independently developed, lightweight Windows utility designed to recreate the classic standalone "About This Mac" interface—styled with an inspired macOS Tahoe aesthetic. Built natively for Windows using WPF (Windows Presentation Foundation), it dynamically pulls your system's hardware configurations and displays them in a sleek, hardware-accelerated dark mode wrapper.

## 🌟 Features

*   **Dynamic Hardware Detection:** Automatically queries and displays your active Windows CPU specs, RAM distribution, and GPU metrics in real-time.
*   **Tahoe Landscape Art:** Integrated custom landscape visual framing to match modern conceptual design structures.
*   **Fluid Animations & Micro-interactions:** Smooth window transitions and responsive interactive states.
*   **Modern Visual Blur:** Incorporates deep translucent blur effects utilizing native Windows composition hooks.
*   **Self-Contained Installer:** Bundled using an automated, localized setup file for easy installation and removal without messy system dependencies.

## 💾 Installation

1. Go to the **Releases** tab on the right side of this repository page.
2. Download the latest `About26_Setup.exe` installer file.
3. Open your directory folder, right-click `About26_Setup.exe`, select **Properties**, check the **Unblock** box at the bottom, and hit **Apply**.
4. Double-click the installer and follow the wizard instructions to choose your shortcut locations and extract the binary safely into your local user directory.

## 🛠️ Technical Details

*   **Framework:** .NET WPF (Windows Presentation Foundation)
*   **Target Architecture:** Windows x64 (Native 64-bit Execution)
*   **Setup Engine:** Inno Setup Compiler Framework
*   **Rendering Type:** Core UI thread-safe hardware metrics parsing
