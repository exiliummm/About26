# About26
An independently developed, lightweight Windows utility designed to recreate the classic standalone "About This Mac" interface—styled with an inspired macOS Tahoe aesthetic. Built natively for Windows using WPF.

## Installation
1. Go to the **Releases** tab on the right side of this repository page.
2. Download the latest `About26_Setup.exe` installer file.
3. Double-click the installer and follow the wizard instructions to choose your shortcut locations and extract the binary safely into your local user directory.

## Technical Details
*   **Framework:** .NET WPF (Windows Presentation Foundation)
*   **Target Architecture:** Windows x64 (Native 64-bit Execution)
*   **Setup Engine:** Inno Setup Compiler Framework
